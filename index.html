1. 共通基礎：電気回路の三要素と「オームの法則」

電気を制御するためには、目に見えない電子の流れを物理的なモデル（水路モデルなど）で正しく把握することが不可欠です。

1-1. 各物理量の本質的意味

  • 電圧 V (Unit: V)：電気的な「位置エネルギーの差（電位差）」です。水路に例えると「水位の高さ（水圧）」です。
  • 電流 I (Unit: A / mA)：断面を1秒間に通過する電荷の量（流れの強さ）です。水路の「水の流量」にあたります。1\text{A} = 1000\text{mA} です。
  • 抵抗 R (Unit: \Omega)：電気の流れにくさです。水路の「川幅の狭さや、障害物の多さ」にあたります。

1-2. 数理モデル：オームの法則

これら3つの関係性は、以下の数式で完全に縛られます。

V = I \times R

2. デジタル出力：LEDの物性と電流制限抵抗の設計

LED（発光ダイオード）は普通の電球とは異なり、「半導体」としての強い物理的特性（極性、順電圧 V_f）を持っています。これを超えると抵抗がほぼゼロになり無限に電流が流れてしまうため、直列に「電流制限抵抗」を配置して回路を守ります。

2-1. 電流制限抵抗の設計計算

【計算プロセス】（目標電流：15\text{mA} = 0.015\text{A}）

  1. 抵抗にかかる電圧：全体電圧5.0VからLEDの順電圧(V_f = 2.0\text{V})を差し引く。
    V_R = 5.0\text{V} - 2.0\text{V} = 3.0\text{V}
  2. 抵抗値の算出：オームの法則（R = V/I）より導出。
    R = 3.0\text{V} / 0.015\text{A} = 200\,\Omega

市販の規格に合わせて安全側に振り、220Ωを実機ではよく使います。

図1. 電流制限抵抗とLEDの配線図
const int LED_PIN = 13; 
void setup() {
  pinMode(LED_PIN, OUTPUT); // 13番ピンを出力モードに設定
}
void loop() {
  digitalWrite(LED_PIN, HIGH); // 点灯
  delay(1000);                 // 1秒待機
  digitalWrite(LED_PIN, LOW);  // 消灯
  delay(1000);
}
練習問題 1：LED電流制限抵抗の設計（計算）

【問題】 Arduinoの5Vピン（またはデジタル出力ピンHIGH）に、順電圧(V_f)が2.6V、定格電流が20mAの青色LEDを接続して安全に光らせたい。このとき直列に挿入すべき電流制限抵抗の理論値は何Ωか求めなさい。

【解答と解説】

1. まず、全体電圧(5.0V)からLEDが消費する分の電圧(2.6V)を引いて、抵抗にかかる分の電圧を求めます。
V_R = 5.0\text{V} - 2.6\text{V} = 2.4\text{V}
2. 定格電流の単位をミリアンペアからアンペアに変換します。
20\text{mA} = 0.02\text{A}
3. オームの法則（R = V/I）に代入して抵抗値を算出します。
R = 2.4\text{V} / 0.02\text{A} = \mathbf{120\,\Omega}
答： 120 Ω

3. アナログ入力：ADCの分解能と可変抵抗による分圧

3-1. 分圧の法則（Voltage Divider）

アナログスティックやボリュームつまみは、内部の可変抵抗の比率（R_1 と R_2）を変えることで、中間のピンから滑らかに変化する電圧 V_{out} を出力します。

V_{out} = V_{cc} \times \frac{R_2}{R_1 + R_2}

3-2. 10ビット解像度のAD変換

Arduino Unoは内部の10ビットADCを用いて、0V〜5Vのアナログ電圧を 0 〜 1023（1024段階）の整数にマッピングします。そのため、プログラム内で電圧値に戻すには、読み取った値に対して以下の計算を行います。

\text{電圧}(V) = \text{analogReadの値} \times (5.0 / 1023.0)

練習問題 2：AD変換値からの電圧復元（計算）

【問題】 Arduinoの `analogRead(A0)` を実行したところ、シリアルモニターに整数値「768」が表示された。このとき、A0ピンに入力されている実際のアナログ電圧は何Vか、小数第3位を四捨五入して小数第2位まで求めなさい。（基準電圧は5.0Vとする）

【解答と解説】

10ビットAD変換では、0V〜5.0Vが0〜1023の1024段階にマッピングされます。
したがって、全体のステップ数「1023」に対する「768」の割合を5.0Vに掛け合わせます。
\text{電圧} = 5.0\text{V} \times \frac{768}{1023} = \frac{3840}{1023} \approx 3.7536\dots\text{V}
小数第3位の「3」を四捨五入して、3.75Vとなります。
答： 3.75 V

4. デジタル入出力の応用：超音波センサーの時間計測と音速の動的計算

超音波センサーは、パルスを送信してから跳ね返って戻るまでの往復時間（Time of Flight）をマイクロ秒単位で計測します。

4-1. 物理数理モデル：音速の温度依存性

音速（v）は固定ではなく、気温（t）に応じて以下の一次関数で変動します。

v = 331.5 + 0.6t \quad [m/s]
練習問題 3：気温を考慮した超音波センサーの距離計算（物理・計算）

【問題】 気温がちょうど15℃の理科室で超音波センサーの実演を行った。センサーのEchoピンから得られた往復パルス時間が2000μs（マイクロ秒）であったとき、測定対象物までの片道距離は何cmか求めなさい。（小数第2位を四捨五入して小数第1位まで答えること）

【解答と解説】

1. まず、気温15℃における音速 v を公式から求めます。
v = 331.5 + 0.6 \times 15 = 331.5 + 9.0 = 340.5\text{m/s}
2. プログラムで扱いやすいよう、「1マイクロ秒あたり何cm進むか」に単位を変換します。
340.5\text{m/s} = 34050\text{cm/s} = 0.03405\text{cm/}\mu\text{s}
3. 往復時間(2000μs)に音速を掛け、片道にするため2で割ります。
\text{距離} = \frac{2000 \times 0.03405}{2} = 1000 \times 0.03405 = 34.05\text{cm}
小数第2位の「5」を四捨五入して、34.1cmとなります。
答： 34.1 cm

5. パルス制御（出力）：DCモーターのPWM制御と数理

Arduinoのデジタルピンは0Vか5Vしか出力できませんが、高速にスイッチングしてON時間の割合（デューティ比）を変えることで、疑似的に中間の平均電圧を作り出すことができます（PWM制御）。

\text{デューティ比}(\%) = \frac{\text{analogWriteの設定値}}{255} \times 100
🚨 モータードライバーICの必要性

DCモーターを停止・反転させた瞬間、コイルの性質により数百ボルトの「逆起電力」が発生します。また、起動には大電流が必要です。これらからマイコンを保護し電力を補うため、必ずモータードライバーICを中間に配線します。

練習問題 4：PWM制御のデューティ比と平均出力電圧（制御工学・計算）

【問題】 ArduinoでDCモーターの速度を調整するため、プログラム内で `analogWrite(9, 102);` と命令を出した。このとき、出力されるPWM波形の①デューティ比（%）と、モーターに実質的に加わる②疑似的な平均出力電圧（V）をそれぞれ求めなさい。（基準電圧は5.0Vとする）

【解答と解説】

analogWriteの引数は0〜255の256段階です。指定値「102」が最大値「255」に対してどれだけの割合かを求めます。

① デューティ比の計算：
\text{デューティ比} = \frac{102}{255} \times 100 = 0.4 \times 100 = \mathbf{40\%}

② 平均出力電圧の計算：
最高電圧5.0Vに対して、デューティ比の割合（40%）を掛け合わせます。
\text{平均電圧} = 5.0\text{V} \times \frac{102}{255} = 5.0\text{V} \times 0.4 = \mathbf{2.0\text{V}}

答： ① 40% 、 ② 2.0 V

6. 位置の制御：サーボモーターのフィードバックシステム

サーボモーターは、20msの周期内にある「HIGHパルスの時間幅（1.0ms〜2.0ms）」によってターゲット角度（0°〜180°）を命令します。内部の角度センサーで常に現在のズレを監視し、自動修正をかけ続ける「フィードバック制御（クローズドループ）」の代表例です。

HIGHパルス幅指示角度
1.0 ms0 度
1.5 ms90 度（中央）
2.0 ms180 度
 
#include <Servo.h>
Servo myServo;

void setup() {
  myServo.attach(10); // 10番ピンをサーボ制御用に指定
}
void loop() {
  myServo.write(90);  // 中央（90度）の位置に保持命令（1.5msパルス自動出力）
  delay(1000);
}
