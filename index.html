4. 重要レッスンの詳細解説とコード構造

■ Lesson 0 & 1: 環境構築とライブラリ管理

Arduinoを動かすためには、PCに Arduino IDE をインストールする必要があります。Windows、Mac、Linuxに対応しており、公式ウェブサイトからインストーラーをダウンロードできます。

ライブラリの追加方法: センサーやディスプレイのコードを簡略化するパーツの集まりをライブラリと呼びます。「スケッチ」＞「ライブラリを含む」＞「ライブラリを管理」から検索して追加するか、提供された「.zip形式のライブラリ」をそのまま読み込ませることで機能拡張が可能です。

■ Lesson 2: 点滅 (Blink) — 初めてのプログラム

ボード上の13番ピンに繋がっている内蔵LED（「L」LED）を制御します。Arduinoプログラムの基本骨格である setup() と loop() の役割を学びます。

int led = 13; // 内蔵LEDが接続されている13番ピン void setup() { pinMode(led, OUTPUT); // 13番ピンを出力モードに設定 } void loop() { digitalWrite(led, HIGH); // LEDを点灯 (5V電圧を出力) delay(1000); // 1秒(1000ミリ秒)待機 digitalWrite(led, LOW); // LEDを消灯 (0Vにする) delay(1000); // 1秒待機 }

💡 応用: delay(1000) の数値を 500 に変更すると、2倍の速さでLEDが点滅するようになります。

■ Lesson 3: LED と抵抗器の重要性

ブレッドボードの仕組み: はんだ付けをせずに電子回路の試作ができる基盤です。内部の穴は縦または横のラインで電気的に繋がっており、パーツの足を差し込むだけで結合できます。両端にある長いライン（電源レール）は、5VとGNDを各部品へ分配するのに便利です。

LEDの極性: LEDにはプラス（アノード）とマイナス（カソード）があります。「足が長い方」または「本体の平らな縁がない方」がプラスです。逆に繋ぐと点灯しません。

抵抗器の役割: LEDに直接電圧をかけると、過電流によって一瞬で焼き切れてしまいます。電流を制限（チョーク）するために必ず抵抗器を直列に入れます。本レッスンでは、抵抗値を 220Ω → 1kΩ → 10kΩ と大きくしていくことで、LEDの輝度がだんだん暗くなる現象を観察します。

■ Lesson 4: RGB LED と PWM（パルス幅変調）

RGB LEDは、1つのパッケージの中に「赤(R)・緑(G)・青(B)」の3つのLEDが入っています。それぞれの明るさを個別に調節することで、光の三原色の原理により、あらゆる色（黄色、紫、白など）を作り出すことができます。

PWM (Pulse Width Modulation) とは: Arduinoのデジタルピン（~マークが付いたピン）は、高速にON/OFFのパルスを繰り返すことで、疑似的にアナログな電圧（0〜255段階）を出力できます。analogWrite(ピン番号, 輝度) を使うことで、LEDの明るさを滑らかに変える（フェードイン・アウト）ことが可能です。

■ Lesson 5: デジタル入力とプッシュボタン

スイッチを押すことでLEDをON/OFFするインタラクティブな回路です。ボタンには4つの足がありますが、内部で2個ずつ繋がっており、実質的には2端子のスイッチとして機能します。

// setup内での特殊な設定 pinMode(buttonApin, INPUT_PULLUP); pinMode(buttonBpin, INPUT_PULLUP);

INPUT_PULLUPの解説: Arduino内蔵のプルアップ抵抗を有効にする設定です。スイッチが押されていない時は常に HIGH に維持され、ボタンが押されてGND（接地）に繋がった瞬間に LOW に変化します。そのため、プログラム上の判定ロジックは「if (digitalRead(buttonPin) == LOW)」の時にボタンが押されたと判断します。
